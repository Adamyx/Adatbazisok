MySQL adatbázis-kezelés alapjai

A weboldal célja a MySQL adatbázis-kezelési nyelv legfontosabb elemeinek bemutatása rövid magyarázatokkal és gyakorlati példákkal. Az oldalon megismerhetők a táblák létrehozásakor alkalmazható korlátozások, valamint az alapvető adatkezelő lekérdezések működése.

Táblákban alkalmazható korlátozások


Korlátozás Leírás Kódpélda
PRIMARY KEY A PRIMARY KEY egyedi azonosítót biztosít minden rekord számára. diak_id INT PRIMARY KEY
FOREIGN KEY Kapcsolatot hoz létre két tábla között. FOREIGN KEY (diak_id) REFERENCES diakok(id)
UNIQUE Egy adott oszlopban nem lehet két azonos érték. email VARCHAR(100) UNIQUE
NOT NULL Nem enged üres értéket megadni. nev VARCHAR(50) NOT NULL
DEFAULT Alapértelmezett értéket ad egy mezőnek. statusz VARCHAR(20) DEFAULT 'aktív'
CHECK Feltételt szab az adatok bevitelére. eletkor INT CHECK (eletkor >= 18)

Lekérdezések típusai


Lekérdezés típusa Leírás Kódpélda
INSERT Új rekord hozzáadása az adatbázishoz. INSERT INTO diakok
(nev, email)
VALUES ('Anna', 'anna@email.hu')
SELECT Adatok lekérdezése az adatbázisból. SELECT * FROM diakok
WHERE eletkor > 18
UPDATE Meglévő adatok módosítása. UPDATE diakok
SET nev = 'Péter'
WHERE id = 1
DELETE Adatok törlése az adatbázisból. DELETE FROM diakok
WHERE id = 5
