MySQL adatbázis-kezelés alapjai

A weboldal célja a MySQL adatbázis-kezelési nyelv legfontosabb elemeinek bemutatása rövid magyarázatokkal és gyakorlati példákkal. Az oldalon megismerhetők a táblák létrehozásakor alkalmazható korlátozások, valamint az alapvető adatkezelő lekérdezések működése.

Táblákban alkalmazható korlátozások


Korlátozás Leírás Példa
PRIMARY KEY A PRIMARY KEY egyedi azonosítót biztosít minden rekord számára. diak_id: 1, 2, 3
FOREIGN KEY Kapcsolatot hoz létre két tábla között. kurzus_id - diak_id
UNIQUE Egy adott oszlopban nem lehet két azonos érték. email: anna@email.hu
NOT NULL Nem enged üres értéket megadni. Kötelező mező
DEFAULT Alapértelmezett értéket ad egy mezőnek. státusz: aktív
CHECK Feltételt szab az adatok bevitelére. életkor: 18+

Lekérdezések típusai


Lekérdezés típusa Leírás Funkció
INSERT Új rekord hozzáadása az adatbázishoz. Adatok beszúrása
SELECT Adatok lekérdezése az adatbázisból. Adatok megjelenítése
UPDATE Meglévő adatok módosítása. Adatok szerkesztése
DELETE Adatok törlése az adatbázisból. Adatok eltávolítása
